## 帖子 1：开跑日 · 观点向（今天发）

中文版：

> AI Agent 开始有自己的链上身份了，但有个问题没人解决：我怎么知道一个陌生的 Agent 值不值得信任？
>
> 钱包地址可以查流水，Agent ID（ERC-8004）可以查注册信息——但「信任」需要的是声誉。
>
> 我的想法：给 BNB 链上每个 Agent 算一个信用分，交易前先查分，就像网购前看店铺评分。
>
> 接下来 3 周，build in public。
>
> #BinanceWalletHackathon #AgenticWallet

English version:

> AI agents now have on-chain identities. But here's the unsolved problem: how do I know a stranger agent is trustworthy?
>
> A wallet address shows you transactions. An Agent ID (ERC-8004) shows you registration. Neither tells you *reputation*.
>
> So I'm building a trust score for every agent on BNB Chain — check the score before you transact, like checking a seller's rating before you buy.
>
> Building in public for the next 3 weeks.
>
> #BinanceWalletHackathon #AgenticWallet

> #BinanceWalletHackathon #AgenticWallet

English version:

> The most important design principle for agent apps: agents propose, humans sign.
>
> Our agent trust-score dApp never touches your keys, never stores sessions, never places orders for you — every review transaction pops up in Binance Wallet for your own confirmation.
>
> That's what an Agentic Wallet should be: AI for efficiency, humans for sovereignty.
>
> #BinanceWalletHackathon #AgenticWallet
