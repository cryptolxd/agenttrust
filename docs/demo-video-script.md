> 用途：项目报名表第 12 题（必填）。录制方式：macOS 按 Cmd+Shift+5 → "录制整个屏幕/所选部分" → 按本脚本操作一遍，约 60 秒。

## 分镜（总计 ~60 秒）

| 时间 | 画面 | 操作 | 旁白/字幕 |
|---|---|---|---|
| 0-8s | 首页 | 打开网站，停留 | "BNB 链上每个 AI Agent，现在都有信用分了" |
| 8-18s | 首页搜索框 | 输入 Agent ID `1`，回车 | "和陌生 Agent 交易前，先查它的分" |
| 18-30s | Agent 详情页 | 展示 owner、注册信息、信用分区域 | "身份信息直接读自 ERC-8004 链上注册表" |
| 30-42s | 评价表单 | 滚动到"写评价"，展示评分滑条、标签、同步 ERC-8004 开关 | "评价是链上交易，每笔都由你在币安钱包确认——我们不碰私钥" |
| 42-52s | Agent ID 门控 | （未连接或无 Agent ID 的钱包）展示领取引导提示 | "只有 Agent ID 持有者能评价，一个 KYC 一票，防刷评" |
| 52-60s | BscScan 页面 | 切到已验证合约页面 https://bscscan.com/address/0xE269D575c0EDd8aa02078FC7Fb01053C17FC66dd#code | "合约已部署主网并验证开源，无 owner 权限" |

## 加分项（如已领取 Agent ID + 币安钱包插件）

把 42-52s 替换为：连接钱包 → 提交一条真实评价 → 钱包弹窗确认 → 链上成功提示。
这会成为"产生链上交互"的第一笔真实数据（把 Q11 也变成 Yes）。
